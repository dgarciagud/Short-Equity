# Short-Equity

Análisis de estrategias cortas semanales y mensuales en acciones del S&P 500. Compara la
teoría *frog in the pan* (caída continua, ID bajo) con el corto en las caídas bruscas, e
incluye el momentum sectorial, la difusión lenta (líder→rezagado y cliente→proveedor), el
momentum residual, y la disyuntiva entre dos sleeves y un meta-modelo.

Usa los datos y las librerías del repo
[stefan-jansen/machine-learning-for-trading](https://github.com/stefan-jansen/machine-learning-for-trading)
(barras AlgoSeek del S&P 500 y `ml4t-data`).
